# ASM1 Game API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the ASP.NET Core + MySQL back-end specified by the ASM1 PDF, verified by 12 Swagger-equivalent HTTP tests.

**Architecture:** Five horizontal layers: Controller → Service → AppDbContext → MySQL. Controllers map HTTP status codes; services own validation, hashing, token creation and ownership checks. Everything is created at runtime from a single `GameApi` project beside the Unity `Assets` folder.

**Tech Stack:** .NET SDK 9.0.203, ASP.NET Core Web API (controllers), EF Core 8.0.31, Pomelo 8.0.3, JwtBearer 8.0.31, Swashbuckle 6.9.0, MySQL 26.10 local.

**Spec:** `docs/superpowers/specs/2026-11-25-game-api-design.md`

## Global Constraints

- Package majors: Pomelo `8.0.3`, EF Core Design `8.0.31`, JwtBearer `8.0.31`, Swashbuckle `6.9.0`.
- Connection string key `Default`; database `game_asm1_demo`; MySQL `localhost:3306`, user `root`, password `123456`.
- JWT key at `Jwt:Key`, at least 32 characters; claim `NameIdentifier` = account id; token lifetime 1 day; HmacSha256.
- `Username` 3–50 unique; `Password` 6–100; `Name` 2–50; `Class` 1–30; `Level` 1–100; `Hp` 0–100000.
- `Level` and `Hp` in `UpdateCharacterRequest` are `int?` with `[Required]`.
- New characters default to `Level=1`, `Hp=100`, UTC `CreatedAt`.
- Login failure message identical for unknown username and wrong password.
- Editing another account's character returns 404, not 403.
- Controllers never inject `AppDbContext`.

## Review Focus

- Missing `hp` on PUT must be 400, not a silent write of 0 — TC11 plus a dedicated missing-field case in `tests/smoke.ps1`.
- Duplicate username must be detected in the service and return 409, never a MySQL exception — TC02.
- Old JWT after account deletion/recreation must not authorize stale account ids — not covered by ASM1; recorded as a limitation.
- Swagger lock icon on register/login is cosmetic; those endpoints must work without a token — TC01 and TC06.
- MySQL server version differs from the PDF demo; Pomelo compatibility is verified by migration plus TC08.
